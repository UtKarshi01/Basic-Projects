# Landing Page

A simple responsive landing page built with HTML and CSS.

## Overview

This project is a static landing page with a dark header and hero section, information cards, a testimonial/quote section, a call-to-action block, and a footer. It follows the classic Odin Project landing page design layout.

## Files

- `index.html` — page structure and content
- `styles.css` — styling and layout for the entire page

## Features

- Clean, modern UI
- Responsive layout for different screen sizes
- Styled CTA buttons and content sections
- Dark theme hero/header/footer styling
- Flexible card grid for the information section

## How to Run

1. Open the project folder in your browser.
2. Double-click `index.html` to view the page.
3. Alternatively, serve it locally with a simple HTTP server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Project Goal

This project demonstrates the use of HTML structure and CSS styling to create a polished landing page without any JavaScript.
